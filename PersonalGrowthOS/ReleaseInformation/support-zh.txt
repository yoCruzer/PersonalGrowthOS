随心log 技术支持

先记录，再回顾
在“记录”中输入文字或选择图片并保存；在“时间线”和“资料库”中回看、搜索和整理。成长页提供习惯、目标、体重、睡眠、时间投入、重要日子和家庭净资产等个人记录入口。核心本地功能不要求注册或登录 iCloud。

保存遇到问题
保留正在编辑的内容，注意 App 显示的错误提示和可用空间。不要删除 App、清空云库或删除恢复副本来尝试修复。若 App 提供“保留数据”导出，请将其安全保存；它可能包含私人内容，不要公开上传。

使用 iCloud
设置 → iCloud 同步，阅读说明后主动连接工作区。设备需使用同一 iCloud 账户并有网络及可用空间。状态页区分上传、下载、待应用和需要处理的情况。网络恢复后可等待自动续传，必要时点击“立即同步”。关闭同步不会自动删除副本。发生冲突或完整性暂停时保留现场，复制诊断后联系支持；不要反复卸载或重建工作区。

备份与恢复
设置 → 数据传输 → 导出完整备份，保存到你信任的位置。备份和 CSV 未加密，请妥善管理。导入完整备份只适用于空数据库；不会自动合并或擦除已有记录。不要以清空日常数据库作为常规测试。

通知、闹钟与小组件
提醒需要你主动开启相应系统权限。拒绝权限不会阻止普通记录。重要日子小组件读取你选择展示的内容；系统刷新时机可能延迟。闹钟功能取决于系统版本和权限。

范围与限制
本 App 用于个人记录。体重、睡眠和成人 BMI 参照不是医疗诊断；家庭净资产为手工人民币余额快照，不连接银行，不提供投资建议。iCloud 同步、备份及导出需要各自管理，不承诺实时完成或恢复所有已删除内容。

提交问题或隐私请求
请通过下方 GitHub Issues 提交脱敏问题。建议包含 App 版本/Build、iOS 版本、最少复现步骤、预期与实际结果；同步问题可附你已检查过的“复制同步诊断”。不需要提供 Apple 账户、密码、验证码、日记正文、健康/资产金额、原图、完整备份或私人路径。
GitHub Issues 公开可见。请只提交不含私人信息的说明；不要在公开问题中上传敏感材料。开发者不会要求你清空真实云库来进行常规排障。
