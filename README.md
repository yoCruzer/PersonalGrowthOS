# PersonalGrowthOS

PersonalGrowthOS is a local-first iPhone life log for capturing text and photos, browsing a unified Timeline, organizing Entries, tracking Habits and Goals/Flags, writing lightweight manual Reviews, recording simple Weight history, and exporting/restoring a complete backup.
